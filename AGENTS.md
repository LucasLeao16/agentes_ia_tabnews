# AGENTS.md

Instruções para agentes de IA que trabalham neste repositório.

## Sobre o projeto

Implementação do [TabNews](https://www.tabnews.com.br) utilizando agentes de IA.

## Stack

- [Next.js](https://nextjs.org) com App Router (diretório `app/`)
- JavaScript (sem TypeScript)
- Consulte o `package.json` para versões e dependências

## Comandos

- `npm install` — instala as dependências
- `npm run dev` — inicia o servidor de desenvolvimento
- `npm run build` — gera o build de produção
- `npm start` — inicia o servidor de produção (após o build)

## Convenções

- Escreva textos da interface, commits e documentação em português.
- Mantenha as mudanças pequenas e focadas no que foi pedido.
